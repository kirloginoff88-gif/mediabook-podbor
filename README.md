# МедиаПодбор — Telegram-бот и мини-приложение подбора рекламы Медиабук

Клиент отвечает на 6 вопросов о бизнесе: ниша, районы Сочи, аудитория, цель, бюджет, экономика. Любой вопрос можно пропустить. Мини-приложение собирает медиаплан из 37 офлайн-направлений reklamavsochi.ru, в приоритете наружная реклама. По каждому каналу считаются контакты, заявки и стоимость заявки, внизу — вывод, почему выбраны именно эти источники.

Кнопка «Отправить план менеджеру»:
- присылает клиенту медиаплан в чат с ботом;
- присылает менеджерам карточку заявки: имя, @username, телефон, источник, план;
- создаёт лид в Битрикс24, если подключён вебхук.

Один сервер на Node.js 20+, без внешних зависимостей.

## Что где лежит

| Путь | Что это |
|---|---|
| `webapp/index.html` | мини-приложение: анкета, движок подбора, база 37 носителей, медиаплан |
| `src/bot.js` | ответы бота: `/start`, `/plan`, `/manager`, `/chatid`, вопросы менеджеру |
| `src/lead.js` | приём заявки из мини-приложения, проверка подписи Telegram, Битрикс24 |
| `src/server.js` | маршруты: `/app`, `/webhook`, `/api/lead`, `/setup`, `/health` |
| `api/index.js` | точка входа для Vercel |
| `src/start.js` | запуск обычным сервером (VPS, Timeweb) |
| `test/run.js` | тесты: `npm test` |

Токены и пароли задаются только в переменных окружения. В git они не попадают.

## Запуск на Vercel (бесплатно, для теста и демо)

1. **Импортируйте проект.** [vercel.com](https://vercel.com) → **Add New → Project** → репозиторий `mediabook-podbor`.
2. **До деплоя задайте переменные** в **Environment Variables**:

   | Переменная | Значение |
   |---|---|
   | `TG_TOKEN` | токен бота от @BotFather |
   | `ADMIN_PASSWORD` | любой пароль для страницы подключения |
   | `MANAGER_CHAT_ID` | пока пусто, см. шаг 5 |
   | `B24_WEBHOOK` | по желанию: входящий вебхук Битрикс24 с правом CRM |

3. **Нажмите Deploy.**
4. **Подключите бота.** Откройте `https://<проект>.vercel.app/setup`, введите `ADMIN_PASSWORD` и нажмите «Подключить бота». Сервер сам выполнит пять действий:
   - поставит вебхук;
   - добавит кнопку меню «Подобрать рекламу», она открывает мини-приложение;
   - задаст команды бота;
   - задаст полное описание;
   - задаст короткое описание.
5. **Включите заявки менеджерам.**
   - Добавьте бота в рабочий чат отдела продаж (или напишите ему в личку) и отправьте `/chatid`.
   - Скопируйте ID в `MANAGER_CHAT_ID`. Для группы ID начинается с минуса; несколько чатов указываются через запятую.
   - Сделайте **Redeploy**.
6. **Проверьте.** Откройте бота, нажмите `/start` → «Подобрать рекламу» → пройдите анкету → «Отправить план менеджеру».

Каждый пуш в `main` разворачивается автоматически. Проверка состояния: `https://<проект>.vercel.app/health`.

> Адреса `*.vercel.app` у части российских мобильных операторов открываются нестабильно, а тариф Hobby — только для некоммерческого использования. Для постоянной работы с клиентами перенесите сервер в Россию: код тот же.

## Сервер в России (постоянная работа)

**Timeweb Cloud App Platform:**
1. Backend → Node.js 22 → этот репозиторий, ветка `main`.
2. Команда запуска `node src/start.js`, проверка состояния `/health`.
3. Те же переменные + `PUBLIC_URL=https://ваш-домен`.
4. Откройте `/setup` на новом адресе: бот переключится сам.

**VPS:** `git clone`, затем `cp .env.example .env` и заполните, затем `node src/start.js` за Caddy или nginx с HTTPS. После запуска откройте `/setup`.

## Источники заявок

Ссылка `https://t.me/<бот>?start=qr_adler` передаёт метку `qr_adler`. Её видно в карточке заявки и в поле источника лида в Битрикс24. Удобно делать отдельные QR-коды для носителей, постов в @mediabooksochi и сайта.

## Данные и допущения

Цены «от», инвентарь по районам и часть охватов взяты со страниц reklamavsochi.ru (ноябрь 2026). Там, где сайт не публикует охват или точный прайс, в модели стоит оценка. В интерфейсе она помечена «оценка». Перед запуском замените оценки на актуальный прайс: массив `F` в `webapp/index.html`.

## Безопасность

- Заявка принимается, только если подпись `initData` от Telegram верна. Подделать заявку от чужого имени нельзя.
- Вебхук проверяет секретный заголовок, выведенный из токена.
- С одного пользователя принимается не больше одной заявки в 30 секунд.
- Если токен где-то засветился: @BotFather → `/revoke` → новый токен в `TG_TOKEN` → Redeploy → снова `/setup`.
